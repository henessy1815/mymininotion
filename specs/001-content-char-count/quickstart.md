# Quickstart: 내용 글자 수 표시 검증

**Feature**: [spec.md](./spec.md) · **Contract**: [contracts/char-count.md](./contracts/char-count.md)

## 사전 준비

```bash
npm install
```

## 1. 자동 테스트

```bash
npm run test:run -- lib/text lib/format "app/(app)/pages"
npm run test:run   # 전체 스위트 — 에러·경고 없는 출력
```

기대 결과: `lib/text.test.ts`, `lib/format.test.ts`, `app/(app)/pages/[id]/page.test.tsx`가 모두 통과한다.
각 테스트의 기대값은 [계약서](./contracts/char-count.md) 표 1·2와 UI 계약 U1~U8에 대응한다.

## 2. 완료 게이트

```bash
npm run lint
npm run build
```

둘 다 오류 없이 끝나야 한다(헌법 품질 게이트).

## 3. 브라우저 수동 확인

```bash
npm run dev
```

로그인한 뒤 `/page`로 새 글을 만들거나 기존 글을 연다.

| # | 조작 | 기대 결과 | 관련 |
| --- | --- | --- | --- |
| 1 | 빈 글을 연다 | 내용 입력칸 아래에 `공백 포함 0자 · 공백 제외 0자` | US1-1 |
| 2 | 한글 IME로 `안녕하세요`를 입력하며 지켜본다 | 조합 중에도 숫자가 바로 바뀌고 마지막에 `공백 포함 5자 · 공백 제외 5자`. 입력이 끊기거나 커서가 튀지 않는다 | US1-2, Edge "한글 조합 중" |
| 3 | Backspace 한 번 | `공백 포함 4자 · 공백 제외 4자` | US1-3 |
| 4 | 내용을 모두 지우고 `가 나`, Enter, `다`를 입력 | `공백 포함 5자 · 공백 제외 3자` | US2 |
| 5 | `👨‍👩‍👧`를 붙여 넣는다 | 공백 포함·제외 모두 1 증가 | Edge "이모지" |
| 6 | 제목을 수정한다 | 글자 수 변화 없음 | FR-006 |

| 8 | 5만 자 텍스트를 붙여 넣고 계속 입력한다 | 입력 반응이 표시가 없을 때와 체감 차이가 없다 | SC-003 |

| 10 | VoiceOver(⌘F5)를 켜고 내용 입력칸으로 이동해 몇 글자 입력한다 | 포커스할 때 글자 수가 설명으로 읽히고, 입력하는 동안 자동으로 낭독되지 않는다 | FR-011 |
